📖 Boîte à histoires NFC – ESP32-S3

Boîte à histoires DIY basée sur un ESP32-S3.

Le principe est simple : une carte NFC correspond à une histoire. L’enfant approche sa carte de la boîte et l’histoire associée est automatiquement lue.

🔧 Matériel

* ESP32-S3 N8R2
* Lecteur NFC PN532
* Carte microSD
* Amplificateur MAX98357A
* Haut-parleur
* Boutons de commande
* Cartes NFC

⚙️ Fonctionnement

Carte NFC → PN532 → ESP32-S3 → microSD → MP3 → MAX98357A → haut-parleur

Les histoires sont stockées sur la carte microSD au format MP3.

Une interface Web permet également de gérer les histoires et les associations avec les cartes NFC.

🎯 Objectif

Créer une boîte à histoires simple pour les enfants, mais entièrement personnalisable et évolutive.

Projet réalisé en DIY avec des composants facilement disponibles.
